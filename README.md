# 时烽德州 · 多人在线德州扑克

和朋友实时对战的德州扑克网页游戏。手机（iPhone）优先的简体中文界面，2–9 人一桌，可以加电脑玩家补位。

> 只使用游戏筹码：没有真钱、没有加密货币，筹码不能购买，也不能兑现。没有任何支付功能。

## 账号与筹码

- 必须注册账号才能玩（不支持游客）。用户名 2–16 位，密码至少 6 位，密码用 bcrypt 加密保存；登录后令牌保存在本机，30 天有效
- **游戏币只能由庄家（管理员）在后台赠送**：注册不送筹码，也没有每日免费领取。余额为 0 时大厅会提示“余额不足，请联系客服获取游戏币”，余额不够带入时不能建房或加入房间
- 客服入口：设置环境变量 `SUPPORT_URL`（例如 Telegram 链接 `https://t.me/xxx`）后，大厅会出现“联系客服”按钮；没设置时只显示文字提示
- 进房间时从余额“带入”房间设定的筹码；离开房间、房间被关闭或清理时，桌上剩余的筹码自动返还到余额；输光后可以从余额补充筹码
- 一手牌进行中离开：自动弃牌，这手结束后返还；一手牌进行中房间被关闭或服务器重启（Render 部署时）：这手作废，所有下注原数退回
- 电脑玩家的带入由“庄家账户”出资，电脑离桌时返还；抽水（可选）也进入庄家账户
- 每一笔余额变动都记流水（管理员赠送/扣除、带入、返还等）
- 旧版本留下的“注册赠送 / 每日领取”设置会在启动时自动清零，`/api/claim` 接口已移除

## 庄家后台 `/admin`

只有管理员账号能进（其他账号访问接口返回 403）。管理员账号在每次启动时根据环境变量 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 创建或更新密码，代码里不保存任何密码。

- 概览：在线人数、房间数、在座真人/电脑、注册人数、庄家余额、桌上筹码、抽水比例；没接数据库时会显示警告
- 玩家：搜索、查看余额和流水；醒目的“🎁 赠送”按钮：快捷金额（1000 / 5000 / 1 万 / 5 万 / 10 万）或自定义数量，备注可不填（默认“管理员赠送”）；也可以扣除；封禁/解封（封禁会把他请出房间并返还筹码、让他下线）
- 房间：查看所有房间（含私密房间）和在线人数、关闭房间、踢出玩家（筹码返还余额）
- 设置：抽水比例（0–10%，翻牌后才抽，不抽没人跟注的部分，从下一手生效）

## 功能

- 大厅“公开房间”列表：显示房间码、房主、人数（含电脑玩家）/9、盲注、起始筹码、等待中/游戏中/已满，实时更新，也可点“刷新”；点一下即可用你的昵称加入
- 创建房间时可选“公开房间”（默认）或“私密房间”：私密房间不出现在列表里，只能凭房间码或邀请链接加入；没有真人在线约 3 分钟的房间会自动关闭
- 创建房间：自动生成 5 位房间码和邀请链接（`https://你的域名/?room=房间码`），朋友点链接或输入房间码、填昵称即可加入
- 房主可设置起始筹码（默认 1000）、盲注（默认 10/20）、每次思考时间（默认 30 秒），可添加/移除电脑玩家，由房主开始游戏
- 完整规则：2–9 人；单挑时庄家下小盲、翻牌前先说话；翻牌前/翻牌/转牌/河牌四轮下注；最小加注规则（短码全下不重新开放加注）；全下与多个边池；摊牌比牌（七选五，含踢脚、平分底池）
- 牌型中文显示：皇家同花顺、同花顺、四条、葫芦、同花、顺子、三条、两对、一对、高牌
- 服务端权威：发牌、下注、比牌都在服务器完成，摊牌前客户端拿不到别人的底牌
- 行动计时：超时自动过牌（不能过牌时自动弃牌）；掉线玩家轮到时自动过牌/弃牌
- 断线重连：刷新页面或网络断开后，凭浏览器里保存的令牌（localStorage）回到原座位
- 每手结束后显示赢家和牌型，8 秒后自动开下一手（房主可立即点“下一手”）；筹码输光即淘汰，只剩一人时游戏结束，房主可“重新开始”
- 绿色牌桌、红黑花色、庄家按钮 D、大小盲标记、当前行动高亮和倒计时条、底池、每人下注、行动记录

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm install
ADMIN_USERNAME=boss ADMIN_PASSWORD=换成你的密码 npm start   # 默认 http://localhost:3000，端口可用 PORT 修改
```

没有设置 `DATABASE_URL` 时，数据保存在本地文件 `data/db.json`（可用 `DATA_FILE` 修改路径），启动时会打印警告。这只适合本地试玩：Render 免费实例每次部署、重启或休眠后文件都会被清空。

用手机测试：电脑和手机连同一个 Wi-Fi，手机浏览器打开 `http://电脑的局域网IP:3000`。

## 部署到公网（Render + 免费 Postgres）

### 1. 准备数据库（二选一）

**推荐：Neon 免费 Postgres**（长期免费，不会过期；1 GB 存储，空闲 5 分钟自动休眠、几百毫秒内唤醒）

1. 用 GitHub 或邮箱注册 https://neon.com ，新建一个 Project（区域选离用户近的，比如新加坡）
2. 在 Dashboard 点 **Connect**，复制连接串（形如 `postgresql://...@...neon.tech/neondb?sslmode=require`）

**或者：Render 自带的免费 Postgres**（Render 面板 **New → Postgres → Free**）

- 注意：免费库创建 **30 天后过期**，过期后 14 天内不升级（最低 $6/月）就会被删除，数据全部丢失；每个账号只能有一个免费库，没有备份
- 创建后在数据库页面复制 **Internal Database URL**

### 2. 在 Render 的 Web Service 里设置环境变量

打开 Render 面板 → 你的 Web Service → **Environment**，添加：

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `DATABASE_URL` | 是 | 上一步复制的 Postgres 连接串。不填也能启动，但会退回本地文件，部署/重启后账号和余额全部丢失 |
| `ADMIN_USERNAME` | 是 | 庄家（管理员）用户名，2–16 位 |
| `ADMIN_PASSWORD` | 是 | 庄家密码，建议 16 位以上随机密码。每次启动都会用它更新管理员密码 |
| `SUPPORT_URL` | 否 | 客服链接（以后的 Telegram 地址）。设置后大厅余额不足提示里会出现“联系客服”按钮 |
| `PGSSL` | 否 | 只有连本机/内网不带 SSL 的数据库时设为 `disable` |

保存后 Render 会自动重新部署。数据表在第一次启动时自动创建，不需要手动建表。

### 3. 部署设置

- Build Command：`npm install`
- Start Command：`npm start`
- Instance Type：Free（15 分钟没人访问会休眠，下次打开要等约 1 分钟；休眠/部署前服务器会把桌上筹码自动返还到余额）

### 也可以用 Railway

Railway 可以一键加 Postgres 插件并自动注入 `DATABASE_URL`，但目前没有长期免费套餐，新账号只有试用额度。

## 文件结构

```
server.js          Express + Socket.IO 服务器：账号、余额、房间、座位、计时、重连、电脑玩家、后台接口
db.js              数据存储：Postgres（DATABASE_URL）或本地 JSON 文件
public/admin.html  庄家后台页面（/admin）
testlib/           测试辅助函数
engine.js          游戏引擎（由 engine.ts 生成的纯 JS，服务器实际使用这个）
engine.ts          游戏引擎源码（带类型）：发牌、下注、比牌、边池、电脑 AI
public/index.html  手机端网页（大厅 + 牌桌），无需构建
test/              单元测试和多客户端联机测试
scripts/build-engine.cjs  修改 engine.ts 后重新生成 engine.js（需 Node 22.13+）
```

## 游戏大厅 & 时烽麻将消消乐

登录后先进入 **时烽游戏大厅**，里面有两款游戏，余额通用（游戏币仍然只能由庄家在后台赠送）：

- **时烽德州**：原来的多人德州扑克房间列表。
- **时烽麻将消消乐**：单人麻将牌转轴消除游戏（原创牌面，CSS/SVG 绘制）。
  - 5 轴 × 4 行、1024 路：同一种牌从第 1 轴开始连续出现在 3 轴以上即中奖。
  - 中奖牌消除、上方牌落下补位，可连续中奖；连消倍数 普通 x1→x2→x3→x5，免费游戏 x2→x4→x6→x10。
  - 「百搭」只出现在第 2–4 轴；3 个以上「胡」触发 10 次免费游戏（每多 1 个 +2 次，可再次触发，最多 100 次）。
  - 下注额：10 / 20 / 50 / 100 / 200 / 500 / 1000 / 2000；单局最高赢下注的 5000 倍。
  - 所有结果在服务器用 crypto 随机数计算（`slot.js`），扣注、派彩、记账、庄家对冲在同一个数据库事务里完成，余额不会变成负数。
  - 设计返还率约 96%（测试里做 100 万次模拟，要求在 94%–98% 之间）。
  - 每局记录在 `slot_spins` 表；玩家可在游戏里看“记录”，庄家后台“麻将”页可看总局数、总下注、总派彩、庄家盈亏和最近记录。

接口：`GET /api/mahjong/config`、`POST /api/mahjong/spin {bet}`、`GET /api/mahjong/history`、`GET /api/admin/mahjong`（管理员）。
